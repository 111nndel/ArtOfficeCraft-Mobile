# ArtOfficeCraft Mobile 0.29.0 — PDF and slide navigation

> Android ARM64 development preview.

## What's New

- Open Reading → Table of contents in PDF to search document bookmarks and jump to their pages.
- Open Reading → Go to page in PDF or View → Go to slide in PowerPoint to jump by number.
- PDFCraft's pinned organize crate resolves local bookmark destinations. These navigation commands work in single-page and continuous reading.

## Known Limitations

- The outline lists up to 4,096 bookmarks. Search matches bookmark titles. Only local page destinations are navigable.
- Android runtime validation uses an emulator.
